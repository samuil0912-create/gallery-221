# Galerie 221 — уебсайт

Едностраничен сайт за салон за красота **Galerie 221** (коса, маникюр/педикюр, козметика). Чист HTML/CSS/JS — без билд стъпка, готов за GitHub Pages.

## Файлове

- `index.html` — цялото съдържание на сайта (на български)
- `styles.css` — дизайн и мобилна версия
- `script.js` — мобилно меню и дребна интерактивност

## Какво да замените с реални данни

Всички места за замяна са отбелязани с `TODO` коментари в `index.html`:

1. **Адрес и телефон** — секция „Контакти“
2. **Instagram / Facebook линкове** — секция „Контакти“
3. **Работно време** — проверете дали е вярно
4. **Снимки в галерията** — плочките сега са цветни плейсхолдъри. Добавете папка `images/` и заменете всяка плочка така:

```html
<figure class="gallery-item">
  <img src="images/pricheska1.jpg" alt="Прическа">
  <figcaption>Прическа</figcaption>
</figure>
```

## Публикуване с GitHub Pages (безплатно)

1. Слейте този branch в `main`
2. В GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. Сайтът ще е на адрес `https://<потребител>.github.io/gallery-221/`

За собствен домейн (напр. `galerie221.bg`) — добавете го в същата настройка Pages → Custom domain.
