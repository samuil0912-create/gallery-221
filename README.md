# Galerie 221 — уебсайт

Едностраничен сайт за салон за красота **Galerie 221** — тъмен, синематичен дизайн с анимации (вдъхновен от activetheory.net). Чист HTML/CSS/JS — без билд стъпка, готов за GitHub Pages.

## Секции

- **Начало** — анимирано заглавие буква по буква, златни частици, custom cursor
- **Услуги** — фризьорство (Kevin Murphy), маникюр/педикюр (IBX), козметика (Wish Pro), дерматология (Teoxane)
- **Продукти** — 3D „орбита“: продуктите се въртят около вертикалното име на марката; превключвател между четирите марки
- **За нас** и **Контакти**

## Файлове

- `index.html` — съдържание (на български)
- `styles.css` — дизайн, анимации, мобилна версия
- `script.js` — частици, 3D орбита, данни за марките и продуктите

## Какво да замените с реални данни

1. **Адрес, телефон, работно време, социални мрежи** — маркирани с `TODO` в `index.html`
2. **Снимки на продуктите** — сега са стилизирани SVG плейсхолдъри. Добавете папка `images/` и в `script.js` задайте на продукта поле `image`:

```js
{ name: 'HYDRATE-ME.WASH', desc: '...', type: 'pump', image: 'images/hydrate-me-wash.jpg' }
```

3. **Описания на продуктите** — редактирайте обекта `BRANDS` в началото на `script.js`

## Публикуване с GitHub Pages (безплатно)

1. Слейте този branch в `main`
2. В GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. Сайтът ще е на адрес `https://<потребител>.github.io/gallery-221/`
