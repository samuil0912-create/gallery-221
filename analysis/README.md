## Възпроизводимост

```bash
cd analysis
for b in 1M 1W 1D 4H 1H 15m; do
  curl -s "https://www.okx.com/api/v5/market/candles?instId=BTC-USDT&bar=$b&limit=300" -o data/$b.json
done
python3 tools/ta.py              # индикатори по таймфрейм -> summary.json
python3 tools/export_chartdata.py  # данни за графиките -> chartdata.js
```

`tools/ta.py` смята EMA, SMA, RSI, MACD, ATR, ADX/DI, Болинджър, StochRSI, обемен профил (POC/VAH/VAL),
суинг върхове и дъна и пивоти — на чист Python, без външни зависимости.
